## What this does not show

- Whether the agent finds the right places: see the last table. Its recall is not better than on the small sandbox, and each size was run once.
- Real documents. The generated ones come from 11 templates and are all Markdown.
- More than 5,021 resources, a bigger code repository, or a taxonomy with more topics.
- The review queue: documents that could not be placed wait for a person, and that number grows with the company (first table).
- Listing a large topic without a filter takes many pages (third table); the agent has to use a type filter, search or find.
